# 📌 Project Overview

FinScoreAI is an AI-powered financial prediction system that analyzes customer information and predicts whether a loan application is likely to be approved or rejected.

The application leverages Machine Learning algorithms trained on credit-related financial data and provides an interactive web interface built with Flask.

The project demonstrates how Artificial Intelligence can assist banks, fintech companies, and financial institutions in assessing credit risk efficiently.
